## 🎯 Phase Overview

Welcome to Phase 1 of your journey from beginner to data professional. Over the next 90 days, you'll build the fundamental skills that every data role requires. This phase focuses on data extraction, analysis, and visualization. These are the core skills that will serve as the foundation for your entire career. But this is not a one time exercise, but a continuous process of learning and improvement.

## 📚 What You'll Learn

- **SQL Mastery**: Extract and manipulate data from databases
- **Python Programming**: The language of data science
- **Statistical Thinking**: Understand what the data is telling you
- **Data Visualization**: Turn numbers into insights
- **Portfolio Project**: Your first complete data analysis

## 🗓️ Day-by-Day Learning Path

### Day 0-15: SQL & Database Fundamentals {#sql-fundamentals}

#### 🎯 **Why Start Here?** {#why-sql}
Every data role begins with data extraction. SQL is the universal language of data. Whether you're at a startup or a Fortune 500 company, you'll need SQL to get data out of databases. Without SQL you might as well be relying on Excel, and we all know how that goes.

Everybody keeps talking about the SQL, but i've never seen the PREQL

#### 📋 **What You'll Learn** {#sql-learn}
- Basic SELECT statements and WHERE clauses
- JOINs to combine data from multiple tables
- Aggregate functions (COUNT, SUM, AVG, etc.)
- Window functions for advanced analysis
- Query optimization basics

### Day 31-45: Statistics & Probability {#statistics}

#### 🎯 **Why This Foundation?** {#why-statistics}
All data science is built on statistical principles. Dont trust anyone who tells you otherwise. Understanding statistics helps you know whether your findings are meaningful or just random chance, and thereby helps you explain it to that stakeholder who thinks "_power of a test_" means how strong the test is, and not a measure of confidence in the test.

Why did the statistician bring a ladder to class?

To reach a higher level of significance.

#### 📋 **What You'll Learn** {#stats-learn}
- Descriptive statistics (mean, median, standard deviation)
- Probability theory basics
- Hypothesis testing
- Statistical significance
- Correlation vs causation

#### 🛠️ **Key Resources** {#stats-resources}
- **Primary - You probably dont need anything else**: <a href="https://www.khanacademy.org/math/statistics-probability" target="_blank">Khan Academy Statistics & Probability</a>

#### ✅ **Day 45 Milestone** {#stats-milestone}

- Tests a hypothesis about your data
- Calculates confidence intervals
- Determines statistical significance
- Explains results in plain English

### Day 46-60: BI & Data Visualization {#bi}

#### 🎯 **Why It's Crucial?** {#why-visualization}
Data is useless if you can't communicate insights effectively. Visualization and BI skills help you tell compelling stories with data. Its almost impossible to hold the attention of a stakeholder for more than 5 minutes, and if you can't communicate your findings in a way that is easy to understand, they will just tune out. 

Always remember data visualization is not about making it look pretty, but making it easy to understand. And tools dont matter unless you are looking for incremental gains. An effective visual can very easily be built in python, but if you want to go that extra mile, my favorite has always been tableau.

### Day 61-90: Capstone Data Analyst Project {#capstone}

#### 🎯 **Why This Project?**
This capstone solidifies your learning and creates something tangible for your resume. You'll work with real-world data pipelines, from data extraction to interactive dashboards. exactly what data analysts do in their day-to-day jobs.

#### 📋 **What You'll Build**
A complete data analysis pipeline including:
- **Data Ingestion**: Pull live data from external APIs using Python
- **Data Storage**: Set up self-hosted database (DuckDB/SQLite) 
- **SQL Analysis**: Write complex queries to extract insights
- **Python Analysis**: Use pandas vs SQL appropriately and document when to use each
- **Interactive Dashboard**: Build with Python (Streamlit/Plotly Dash) or free Tableau
- **Documentation**: GitHub repository with comprehensive README and analysis notebooks

#### 🎯 **Project Ideas**
Choose one that interests you:
- **E-commerce**: Pull product data from Amazon/eBay APIs, analyze pricing trends
- **Finance**: Fetch stock market data from Yahoo Finance, create portfolio analysis
- **Weather**: Get weather data from OpenWeatherMap, analyze climate patterns
- **Social Media**: Use Twitter/X API to analyze tweet sentiment and engagement
- **Sports**: Pull sports statistics from API, analyze team/player performance
- **Crypto**: Fetch cryptocurrency data from CoinGecko, analyze market trends

#### 🛠️ **Technical Stack You'll Use**
- **Data Source**: Public APIs (Reddit, Twitter, Weather, Financial, etc.)
- **Database**: DuckDB (recommended) or SQLite for local data storage
- **Languages**: Python for data ingestion and analysis
- **SQL**: Complex queries for data extraction and aggregation
- **Tools**: Jupyter Notebooks for analysis, Git for version control
- **Dashboard**: Streamlit/Plotly Dash (free) or Tableau Public (free tier)
- **Documentation**: GitHub with README, notebooks, and project documentation

#### 📋 **Step-by-Step Implementation**

**Week 1 (Days 61-67): Data Pipeline Setup**
- Choose your data source and get API keys
- Write Python scripts to pull data from external APIs
- Set up DuckDB/SQLite database and schema
- Create automated data ingestion pipeline
- Handle data cleaning and validation

**Week 2 (Days 68-74): SQL Analysis & Python Integration**
- Write complex SQL queries for data extraction
- Learn when to use SQL vs pandas (document your decisions)
- Create analysis notebooks with both SQL and pandas operations
- Perform exploratory data analysis
- Document your findings and methodology

**Week 3 (Days 75-81): Dashboard Development**
- Choose your dashboard tool (Streamlit recommended for beginners)
- Build interactive visualizations and filters
- Implement real-time data updates (if possible)
- Create user-friendly interface for stakeholders
- Test dashboard functionality and performance

**Week 4 (Days 82-90): Documentation & Deployment**
- Set up Git repository and learn version control basics
- Write comprehensive README with project overview
- Document your data pipeline and analysis methodology
- Create Jupyter notebooks with your analysis
- Deploy your dashboard (if possible) and prepare presentation

A complete GitHub repository with:

## 💡 Tips for Success

### 🧠 The Right Mindset
Building data skills isn't about memorizing formulas or becoming a math genius. It's about becoming curious and asking good questions. Think of yourself as a detective - your job is to find clues in data and tell the story they reveal. Stay curious about why things are the way they are, and don't be afraid to say "I don't know" when you genuinely don't have the answer.

### 🚧 Common Mistakes to Avoid
Everyone gets stuck sometimes, and that's totally normal. The biggest mistake is trying to learn everything at once. Pick one thing, get good at it, then move to the next. Don't spend weeks perfecting a visualization that's "good enough." Don't get lost in tutorial hell without actually building anything. And please don't compare your beginning to someone else's middle - we all start somewhere.

### 📈 Growing Your Career
Your portfolio is more important than your resume. Build projects that solve real problems, even if they're small. Share what you're learning on LinkedIn or a blog - it helps you understand topics better and shows others you're actively learning. Find people who are further along than you and ask for advice. Most people in data are happy to help newcomers because they remember what it was like starting out.won't be perfect, and that's okay
